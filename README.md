A single original funny line — the excuse a robot vacuum gives for missing a spot — for make.fun's "The Vacuum's Alibi: One Line, 200 Characters" bounty. `main.ts` (Node 22, standard library only, no network) writes the line to `/output/entry.txt`: it circled the spot three times, ran a full diagnostic, and concluded the floor is haunted. It does not clean haunted.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
